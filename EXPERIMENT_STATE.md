# Experiment state and hand-off

Last updated: 2026-09-17 (Asia/Taipei)

This is the canonical hand-off document for the current texture-classification
experiment. A new Codex session should read this file before interpreting the
older reports. The older DCT experiments are retained for provenance, but the
current main line is:

```text
clean image -> P (stride-1, overlap average) -> clean soft teacher map
noisy/clean image -> G -> dense per-pixel approximation of that P map
```

`P` means the spatial 32x32 texture patch CNN (formerly STCNN or Spatial32).
`G` means the dense residual U-Net-like texture-map generator. The old DCT
classifier is a historical baseline, not the teacher used by the newest G
checkpoints.

## 1. What the task means

The output is a single soft texture probability map in `[0, 1]`. Values near 1
mean that local visible detail should be treated as texture under this
experiment's operational definition; values near 0 mean smooth/non-textured.
Thresholding at 0.5 gives one binary map, not two separate output images.

This is not semantic segmentation and does not group pixels by material or
object identity. The pseudo-label definition is based on clean-image Sobel
strength, so it emphasizes visible local variation. It is neither human ground
truth nor a universal definition of texture.

## 2. Dataset and pseudo-label construction

### 2.1 P patch dataset

Source split:

| Split | Source | Images | Balanced samples |
|---|---|---:|---:|
| Train | DIV2K `DIV2K_train_HR` | 800 | 6,000 = 3,000 texture + 3,000 non-texture |
| Validation | DIV2K `DIV2K_valid_HR` | 100 | 2,000 = 1,000 + 1,000 |

The train and validation image sets are disjoint. All 800 train images
contributed at least one positive/negative pair. The full images are not all
fed to P as training samples; the counts above are extracted contexts.

Exact label procedure (`build_dataset.py` and `build_context_dataset.py`):

1. Convert each clean image to luminance and compute Sobel magnitude.
2. Find the `100x100` window with the highest mean Sobel magnitude and label it
   the texture region; find the lowest window and label it non-texture.
3. Randomly sample paired `8x8` target patches inside those two regions. Sample
   counts are allocated across all source images to reach 3,000 train pairs and
   1,000 validation pairs.
4. For P, recover the original image coordinates and extract a centered
   `32x32` grayscale context around each `8x8` target. The target remains the
   high/low-region binary pseudo-label.

Important: the current dataset does **not** pool every `100x100` window from all
images and then retain global top/bottom quartiles. It selects one high and one
low window per image, then samples within them.

Dataset files under `data/` are intentionally ignored by Git because DIV2K and
generated NPZ files are large. They can be rebuilt with:

```bash
python build_dataset.py \
  --train-dir /path/to/DIV2K_train_HR \
  --val-dir /path/to/DIV2K_valid_HR

python build_context_dataset.py \
  --train-images /path/to/DIV2K_train_HR \
  --val-images /path/to/DIV2K_valid_HR
```

The committed code, summaries, checkpoints, metrics, and selected result images
are sufficient to inspect the completed experiments, but retraining requires a
separate DIV2K download.

### 2.2 G dense-map dataset

| Split | Source images | Crops/image | Total crops | Crop size |
|---|---:|---:|---:|---:|
| Train | same 800 DIV2K train images | 2 | 1,600 | `128x128` |
| Validation | same 100 DIV2K validation images | 2 | 200 | `128x128` |

The current target dataset is `data/map_generator_stcnn_v1` and is generated by
`build_stcnn_map_dataset.py`. Each clean crop is passed through
`checkpoints/stcnn_limit/stcnn_diverse_conditioned_oracle.pt` with exact
`sigma=0`. P is evaluated densely at stride 1; overlapping central-8x8 scalar
predictions are averaged into a soft native-resolution target. The old DCT
classifier has no role in these new targets.

Recorded target statistics:

- Train mean probability `0.48563`; fraction >= 0.5 `0.48254`.
- Validation mean probability `0.50361`; fraction >= 0.5 `0.50226`.

The NPZ files are ignored and must be regenerated after building the older crop
dataset:

```bash
python build_stcnn_map_dataset.py \
  --source-dir data/map_generator_v2 \
  --output-dir data/map_generator_stcnn_v1 \
  --teacher checkpoints/stcnn_limit/stcnn_diverse_conditioned_oracle.pt
```

## 3. Noise generation

All intensities are normalized to `[0,1]`; parameters described as 8-bit units
are divided by 255 before addition. Values are clipped to `[0,1]`. During
six-family training one family is selected independently for each sample:

| Family | Training range / implementation |
|---|---|
| AWGN | sigma uniformly sampled from `[0,100]` |
| Correlated Gaussian | initial sigma in `[10,60]`; Gaussian field is 3x3 average pooled and multiplied by 3 |
| Poisson | peak uniformly sampled from `[5,60]`; `Poisson(clean*peak)/peak` |
| Speckle | multiplicative standard deviation in `[0.05,0.30]` |
| Salt-and-pepper | total probability in `[0.005,0.05]`, split equally between 0 and 1 |
| Sinusoidal/banding | amplitude in `[5,30]` 8-bit units, period `[2,8]` px, random angle and phase |

For AWGN, sigma 50 means a pre-clipping Gaussian standard deviation of 50
intensity levels: about 68% of samples lie within +/-50 and 95% within +/-100.
That is severe compared with ordinary well-exposed optical imagery.

P training uses paired clean/noisy examples. It applies the same hard clean
pseudo-label to both, and adds a clean/noisy probability-consistency loss. Thus
the published robust P models **have seen synthetic noisy images**.

Conditional P receives the measured per-patch corruption RMS as an extra input,
normalized by 50. Conditional G receives per-crop RMS normalized by 100. Exact
RMS is an oracle in synthetic experiments because the clean source is known; it
is not automatically available for a real noisy photograph.

## 4. P architectures and dense inference

Every P model receives a grayscale `1x32x32` spatial-domain context, normalized
as `(x - 0.5) / 0.25`, and predicts one scalar probability for its central
`8x8` target. P does not receive a DCT image or DCT coefficients.

| P variant | Architecture summary | Parameters | FP32 weights |
|---|---|---:|---:|
| Compact `spatial32` | Conv `1-8-16-32`, three 2x pools; FC `512-64-16-1` | 39,777 | about 155 KiB |
| Conditional `spatial32_conditional` | compact backbone; sigma MLP `1-16-32`; FC `544-64-16-1` | 42,401 | about 166 KiB |
| Large `spatial32_large` | Conv `1-32-64-128`, three 2x pools; FC `2048-256-64-1` | 633,729 | about 2.42 MiB |

Old stride-8 rendering repeats each scalar over a non-overlapping `8x8` block,
which creates artificial grid/mosaic boundaries. Current dense inference uses
all stride-1 `32x32` contexts, spreads each scalar over its central `8x8`, and
averages every overlap. It preserves the original HxW size and does not resize
the image.

On 200 held-out DIV2K validation crops, stride-1 reduced the exact-flat neighbor
fraction from 88.29% to 0.85%, and made 1-7 pixel translations effectively
equivariant. With the compact distilled P, self-consistency to its clean output
was 98.34% at AWGN 15, 95.61% at AWGN 50, and 88.59% at AWGN 100. These are
agreement-to-clean-output values, not human-label accuracy.

## 5. Published P checkpoints and correct usage

There is no single globally "best P". Use role-specific names:

| Name used here | Checkpoint | Parameters | Intended role |
|---|---|---:|---|
| P-clean-teacher | `checkpoints/stcnn_limit/stcnn_diverse_conditioned_oracle.pt` | 42,401 | Generate clean targets with known `sigma=0`; high clean validation score, but can suppress real texture at high supplied sigma |
| P-robust | `checkpoints/stcnn_limit/stcnn_diverse_teacher.pt` | 633,729 | Direct inference on noisy images without sigma metadata; most stable current deployment candidate |
| P-distilled | `checkpoints/stcnn_limit/stcnn_diverse_distilled.pt` | 39,777 | Compact non-conditional robust compromise distilled from the large P |
| P-sigma-robust | `checkpoints/stcnn_limit/stcnn_diverse_sigma_robust.pt` | 42,401 | Conditional experiment with sigma jitter/randomization; less dependent on exact metadata |
| P-AWGN100 | `checkpoints/stcnn_limit/stcnn_awgn100_paired.pt` | 39,777 | AWGN-specific paired experiment, not the preferred mixed-noise model |

Representative balanced validation accuracy from the six-family study:

| Model | Clean | AWGN 100 | Corr. Gaussian 50 | Poisson peak 10 | S&P 5% | Sine amp 30 |
|---|---:|---:|---:|---:|---:|---:|
| P-distilled | 96.30% | 93.95% | 82.11% | 96.21% | 96.41% | 96.07% |
| P-clean-teacher, exact sigma | 98.50% | 91.66% | 94.06% | 97.50% | 97.25% | 97.66% |
| P-robust large | 97.65% | 94.07% | 89.27% | 97.09% | 97.58% | 95.13% |

Checkpoint training details:

- P-clean-teacher: six-family paired training, exact RMS conditioning, selected
  at epoch 147, seed `20264115`.
- P-robust: six-family paired training without conditioning, epoch 150, seed
  `20264117`.
- P-distilled: compact student, alpha 0.5, temperature 2.0, consistency weight
  1.0, epoch 180, seed `20265915`.
- Standard six-family runs used AdamW, learning rate `1e-4`, weight decay
  `1e-4`, batch size 256, and consistency weight 1.0.

External grass-suite results expose the key trade-off. P-clean-teacher marks
`piqsels_grass` as 99.7% texture when clean, but only 52.8% at AWGN 50. P-robust
is much more stable across noise, yet marks only 4.0% of that clean low-contrast
grass image as texture. Robustness is therefore partly achieved by rejecting
fine stochastic real texture.

The external suite is now a qualitative validation/stress set because it was
repeatedly inspected during model selection. It is **not** a pristine blind
final test set. `div2k_0524` is from DIV2K train and cannot demonstrate
generalization. The `validation_comparison` crops are from DIV2K validation.

## 6. G architecture, training, and checkpoints

G receives a full grayscale luminance crop/image and outputs one same-size
pixel-logit map. After sigmoid this is the dense texture probability map.

Architecture: residual U-Net with three stride-2 downsampling stages,
`c -> 2c -> 4c -> 8c`, a residual bottleneck, transpose-convolution upsampling,
skip concatenation, residual decoder blocks, and a final `1x1` one-channel
output. Conditional G concatenates a constant sigma map as a second input
channel.

| G size | Base channels | Parameters | FP32 weights |
|---|---:|---:|---:|
| Tiny | 8 | 190,753 | about 0.73 MiB |
| Compact | 16 | 761,665 | about 2.91 MiB |
| Large | 32 | 3,043,969 | about 11.61 MiB |
| X-large | 64 | 12,170,497 | about 46.43 MiB |
| Conditional compact | 16, two input channels | 761,825 | about 2.91 MiB |

Current G training uses each clean crop and a random six-family corrupted
version. Both clean and noisy predictions are supervised toward the same clean
P soft target with MSE; noisy/clean prediction consistency has weight 0.25.
Default optimizer is AdamW, learning rate `1e-4`, weight decay `1e-5`, batch
size 16, at most 50 epochs, early-stop patience 10.

Current P-teacher G checkpoints:

| Checkpoint | Parameters | Selected epoch | Validation balanced agreement to clean P target: clean / AWGN50 / AWGN100 / correlated50 |
|---|---:|---:|---:|
| `g_diverse_compact.pt` | 761,665 | 47 | 91.32 / 88.36 / 82.51 / 67.17% |
| `g_diverse_large.pt` | 3,043,969 | 30 | **92.65 / 90.00 / 83.51 / 77.71%** |
| `g_diverse_distilled.pt` | 761,665 | 48 | 91.46 / 89.55 / 83.14 / 74.69% |
| `g_diverse_conditional_oracle.pt` | 761,825 | 50 | 92.86 / 85.38 / 79.51 / 73.96% |
| `g_diverse_conditional_robust.pt` | 761,825 | 47 | 93.70 / 86.85 / 83.73 / 72.14% |

These metrics compare G with the clean P target on held-out DIV2K crops. They
are not semantic accuracy, human GT accuracy, or directly comparable to P's
balanced patch classification accuracy.

The important current G failure is out-of-distribution teacher imitation:
P-clean-teacher marks clean `piqsels_grass` almost entirely as texture, while
the non-conditional compact/large/distilled G models mark roughly 0.5/0.8/0.3%.
G does not call P at inference; it only learned from P targets on DIV2K crops.
Strong in-domain validation scores therefore do not guarantee imitation on a
new material distribution.

## 7. Historical DCT baseline

The old `8x8` DCT CNN has 14,113 parameters (14,177 with sigma). It transforms
the grayscale `8x8` patch with an orthonormal 2-D DCT and standardizes each
coefficient before classification. It used the same clean Sobel-extreme
pseudo-label definition. The clean-only DCT baseline reached 96.20% held-out
patch accuracy but collapsed under large AWGN; robust DCT variants improved but
were inferior to spatial-context P.

The old reports and old G checkpoints remain useful to document the path of the
research, but their teacher-specific G metrics must not be mixed with the new
P-teacher G results.

## 8. Most important conclusions now

1. Spatial `32x32` P is the current patch-classifier main line; DCT is a
   historical baseline. P's extra spatial context is more useful than forcing
   the model into the frequency domain.
2. Use stride-1 overlap averaging for dense P maps. Stride-8 outputs are a
   diagnostic that contain rendering artifacts.
3. P-clean-teacher and P-robust solve different problems. Do not call either
   globally best.
4. A single noisy `32x32` observation can make low-contrast stochastic texture
   statistically indistinguishable from a smooth signal plus correlated noise.
   More model capacity alone cannot guarantee separation.
5. G's main limitation is now OOD imitation of P, especially on fine grass,
   rather than only parameter count.
6. A trustworthy next conclusion requires a new final test set not used for
   model selection, ideally with human/material texture annotation or controlled
   clean/noisy ground truth.

Recommended next experiments, in order:

1. Freeze the current external suite as validation and create a new blind final
   test set.
2. Improve ground truth: human review, material-aware labels, or controlled
   clean/noisy pairs. Sobel pseudo-labels cannot answer every texture question.
3. Test larger/multi-scale P context and, where available, multiple frames or
   calibrated noise metadata to break the texture/noise ambiguity.
4. Expand G's P-target training distribution with diverse materials while
   keeping the final test untouched; re-evaluate OOD teacher agreement.
5. Compare direct P inference with G on matched dense metrics, runtime, memory,
   and OOD cases before choosing a deployment path.

Current practical choices:

- Clean target generation: P-clean-teacher with exact `sigma=0`.
- Direct noisy inference without metadata: P-robust large.
- Compact robust P: P-distilled.
- Best current in-domain dense G: large P-teacher G, with the OOD warning above.

## 10. Reproducibility and repository boundaries

Run tests after cloning:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

The repo intentionally commits source code, compact checkpoints, reports,
machine-readable metrics, and selected result images. It intentionally does not
commit DIV2K, generated NPZ/NPY tensors, raw `outputs/`, or logs. Paths recorded
inside old JSON/checkpoint metadata may show the original Windows workspace;
commands should use repository-relative or local dataset paths on a new machine.

Do not interpret heatmap color as accuracy. The committed galleries use TURBO:
blue/purple is probability near 0 and red is near 1. Text such as `P>=0.5:
32%` means 32% of pixels were classified as texture, not 32% accuracy.
